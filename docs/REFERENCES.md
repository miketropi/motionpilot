# References and compatibility

MotionPilot's rules are inspired by widely used professional editing, UI/UX and multimedia-learning practices. **References are not bundled dependencies or endorsements.** No proprietary assets, presets, paid model weights or copied third-party skill contents are included.

## Standards and installation

- [Agent Skills specification](https://agentskills.io/specification) — SKILL.md metadata, directory discovery, progressive disclosure.
- [skills CLI by Vercel Labs](https://github.com/vercel-labs/skills) — installation via `npx skills add owner/repo`, selective skill installation and updates.
- [CLI reference](https://github.com/vercel-labs/skills/blob/main/docs/commands.md) — `--list`, `--all`, `--skill` and `-g` usage.

## Visual/video production

- [Remotion](https://www.remotion.dev/docs/) — composition, timeline, animation and video rendering patterns.
- [Remotion Skills](https://github.com/remotion-dev/skills) — task-oriented video authoring examples.
- [Emil Kowalski Skills](https://github.com/emilkowalski/skills) — refined web/interaction animation design references.
- [Impeccable](https://github.com/pbakaus/impeccable) — design critique, visual hierarchy and polish references.
- [UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — cross-format visual design references.

## Audio

- [ElevenLabs Skills](https://github.com/elevenlabs/skills) — narration, music and semantic sound-effects workflows.
- [Remotion Audio](https://www.remotion.dev/docs/audio) — programmatic audio on video timelines.
- [FFmpeg](https://ffmpeg.org/ffmpeg-filters.html) — audio normalization, compression, fades and decoding.
- [EBU R 128](https://tech.ebu.ch/publications/r128) — loudness measurement reference.

## Learning design

- [Mayer, Multimedia Learning](https://www.cambridge.org/highereducation/books/multimedia-learning/94EFD16DE33BBE060B1A7D3385C926B5) — segmenting, signaling and cognitive-load-informed instruction. Apply heuristics thoughtfully and validate with actual users.

## Interpretation

- Repo popularity or installation counts are **signals of adoption**, not direct proofs of improved educational outcomes.
- Provider quality, licensing and cost may change. Validate current model and music/voice rights when running a production.
- MotionPilot is provider-neutral: use authorized tools available in the execution environment.
